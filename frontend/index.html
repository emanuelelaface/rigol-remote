WORKBENCH GUIDE

Built around the signal.

Waveforms transfers calibrated 8-bit screen samples for the enabled analog and math traces and draws them locally. Time-domain math uses the instrument’s MATH scale and position. FFT is shown in its own frequency plot. The fps counter measures received frames, not the instrument’s internal acquisition rate. Sources are read sequentially.

Display markers show the edge-trigger voltage as a channel-colored horizontal line and time zero as an amber vertical line. Edge indicators show when either position is outside the visible plot.

Instrument screen shows the original display, including decoding, menus and hardware cursors. Screenshots take longer to transfer.

Local cursors and persistence only affect this browser. The side panel controls the physical instrument. CSV exports the last acquired screen samples; memory ZIP downloads the full stopped acquisition with calibration metadata.

Shared session: browser tabs connected to this server control the same instrument. Pause view suspends streaming for all tabs; it does not stop acquisition.
